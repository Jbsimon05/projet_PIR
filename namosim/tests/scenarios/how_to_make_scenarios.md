# Comment qu'on fait des scénarios 

- toutes les unités du SVG sont en centimètres (les cases font 1 mètre)
- utiliser inkscape parce que cool askip
- le tag <namo_config> donne tous les paramètres
- il faut que tous les objets soient des <svg:path>
- transformer en path avec Path->Object to Path
- donner un id, les id sont pas spécialement formatés
- l'angle par défaut c'est 0
    - attribut `angle` à rajouter qq part pour avoir un robot qui commence à un angle différent

- passer au debugger parce que c'est cool
